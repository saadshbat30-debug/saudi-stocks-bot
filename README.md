# منصة الأسهم الأمريكية — الزخم والسيولة (كل الأسهم وكل الأسعار)

تعمل **بدون أي توكن أو مفتاح** — شغّلها وافتح الموقع.

## الصفحة الرئيسية
- **شريط المؤشرات**: داو جونز، ناسداك، S&P 500، راسل 2000 + حالة السوق (مفتوح / قبل الافتتاح / بعد الإغلاق / مغلق)
- **نظرة على السوق**: مرتفع / ثابت / منخفض، قيمة التداول الإجمالية، عدد الأسهم بسيولة عالية وعند قمة اليوم
- **لوحات سريعة**: 🚀 أقوى زخم (5 دقائق) · 💧 أعلى سيولة نسبية · 💰 الأعلى قيمة تداول
- **قوائم**: الأكثر ارتفاعًا، الأكثر انخفاضًا، الأكثر نشاطًا، الأعلى قيمة، الزخم، السيولة، عند قمة اليوم، المفضلة
- **الجلسة الرسمية / قبل وبعد الجلسة / 🌙 التداول الليلي** (8 مساءً – 4 فجرًا بتوقيت نيويورك، Blue Ocean ATS)
- `/api/raw/<الرمز>`: البيانات الخام من ماسح ياهو لفحص أسماء الحقول
- **فلاتر**: السعر (تحت 1$ · 1–5$ · 5–20$ · 20–60$ · 60–200$ · 200$+)، السوق (الكل · المدرجة · OTC)، الإشارات (تشبع بيعي/شرائي، اتجاه صاعد/هابط)، بحث
- **🧩 فلتري**: اختر أي مجموعة شروط (السعر، التغير، الفجوة، الحجم، القيمة، السيولة النسبية، التدوير، RSI، الأسهم الحرة، القيمة السوقية، تسارع الحجم، نطاق 3 دقائق، فوق المتوسطات…) بحد أدنى وأعلى، مع قوالب جاهزة، وتُحفظ في المتصفح
- **⚡ قبل الانطلاق (PRE-BREAKOUT V1.0)**: يرصد تسارع الحجم والسعر في نطاق ضيق من البث اللحظي (الجلسة الرسمية بعد 9:35 ص نيويورك)، ويسجل كل إشارة ويتابعها 3 دقائق، مع إحصائيات النجاح حسب الهدف/حد الهبوط/المدة المختارة (`data/breakout_signals.json`)
- **📑 العقود (كول وبوت)**: سلسلة الخيارات لأي سهم من ياهو (متأخرة ~15 دقيقة) لكل تواريخ الانتهاء، مع الدلتا واحتمال الانتهاء داخل السعر (بلاك-شولز)، نسبة البوت/الكول، Max Pain، الحركة المتوقعة، تمييز النشاط غير المعتاد 🔥، وحاسبة ربح/خسارة للعقد
- **🔎 فلتر العقود**: يبحث في عدة أسهم معًا بشروط: مدة الانتهاء، الدلتا، الحجم، العقود المفتوحة، فرق العرض/الطلب ($ و %)، IV، بُعد الإضراب، تكلفة العقد، احتمال ITM، حركة التعادل، واستبعاد العقود عكس اتجاه السهم — مع قوالب (متوازن · محافظ · مضاربة)
- **💼 صفقتي**: خانة عائمة في كل الصفحات — سعر الشراء والكمية والمبلغ، وقف 1/2 وهدف 1/2 كخطوط على الشارت مع تنبيهات، والربح/الخسارة لحظيًا
- **🇺🇸 / 🇸🇦 السوقان في منصة واحدة**: زر تبديل أعلى كل صفحة، ومنصة أبو طلال للسوق السعودي (tasi-intel) تُعرض في صفحة `/saudi`. `py app.py` يشغّلها تلقائيًا في نفس النافذة إذا كانت مثبتة في `C:\Users\<اسمك>\tasi-intel` (أو `SAUDI_DIR`)، وتتوقف معها. لإيقاف التشغيل التلقائي: `SAUDI_AUTOSTART=0`

### الأعمدة
| العمود | المعنى |
|---|---|
| سرعة 5د | نسبة تغير السعر خلال آخر 5 دقائق (الزخم اللحظي) |
| القيمة | السعر × الحجم بالدولار |
| السيولة × | حجم اليوم ÷ متوسط حجم 3 أشهر |
| التدوير % | الحجم ÷ عدد الأسهم القائمة |
| الاهتزاز % | (أعلى − أدنى) ÷ إغلاق أمس |
| RSI | مؤشر القوة النسبية 14 يوم |
| P/E · P/B | مكرر الأرباح · مضاعف القيمة الدفترية |

### الأخبار والإيقافات والأسهم الحرة
- **📰 الأخبار**: أخبار الأسهم الأكثر حركة في اللوحة الجانبية، وأخبار كل سهم في صفحته (من ياهو)
- **⏸️ إيقافات التداول**: إيقافات اليوم من Nasdaq لكل البورصات (LULD، بانتظار خبر...) مع سبب الإيقاف ووقت الاستئناف، علامة «موقوف» على السهم، تبويب «موقوفة»، وتنبيه عند الإيقاف والاستئناف
- **🎯 الأسهم الحرة (Float)**: تُجلب تدريجيًا في الخلفية وتُحفظ في `data/floats.json`؛ تبويب «أسهم حرة قليلة» (أقل من 20 مليون، `LOW_FLOAT`)، والتدوير يُحسب من الأسهم الحرة مثل موموو
- **🎯 تنبيهات السعر**: من صفحة السهم (أو أزرار سريعة ±5/10/20%)، تظهر خطًا متقطعًا على الشارت وتنبه بصوت وإشعار

### التنبيهات (صوت + إشعارات المتصفح)
تغير ±10% · زخم ±3% خلال 5 دقائق · سيولة 3× المعتاد

## صفحة السهم
- **السيولة اللحظية** (تتحدث كل 5 ثوانٍ): حجم اليوم، قيمة التداول، السيولة × المعتاد، التدوير، سرعة 5د،
  والسيولة **الداخلة / الخارجة / الصافي** لليوم وآخر 5 و15 دقيقة (تقدير من شموع الدقيقة + البث المباشر)
- شارت لحظي (شموع 1د/5د/15د/ساعة/يوم، آخر شمعة من البث المباشر) + تبويب TradingView الكامل (متأخر 15 دقيقة)
- **مؤشرات MACD (12، 26، 9) و RSI (14)** في نوافذ أسفل الشارت، متزامنة معه في التمرير والتكبير والمؤشر
- **أدوات رسم كاملة التحكم**: خط أفقي، اتجاه، شعاع، سهم، قناة متوازية، عمودي، مستطيل، فيبوناتشي، قياس، نص
  - اضغط أي رسمة لتحديدها، اسحبها لتحريكها، واسحب مقابضها لتعديلها
  - شريط خصائص: اللون، السماكة، النمط (متصل/متقطع/منقط)، قفل، نسخ، حذف، تعديل النص
  - Delete للحذف، Esc للإلغاء، Ctrl+Z للتراجع عن أي تعديل، مغناطيس، إخفاء الكل — تُحفظ لكل سهم

## مصدر البيانات
قائمة الأسهم من ماسح Yahoo Finance (ناسداك ونيويورك وأمكس، بدون OTC والوارنتات والحقوق والأسهم الممتازة)،
والأسعار **لحظية** من البث المباشر لياهو (⚡).

## التشغيل على جهازك (ويندوز)
```powershell
cd $HOME\saudi-stocks-bot
git pull
py -m pip install -r requirements.txt
py app.py
```
ثم افتح http://localhost:5000

## الإعدادات (كلها اختيارية — متغيرات بيئة)
| المتغير | الوصف | الافتراضي |
|---|---|---|
| `MIN_PRICE` / `MAX_PRICE` | النطاق السعري (فارغ = بدون حد أعلى) | `0` / بدون حد |
| `US_LIMIT` | أقصى عدد أسهم مدرجة (حسب الحجم) | `1000` |
| `OTC_LIMIT` | أقصى عدد أسهم OTC (`0` لإيقافها) | `250` |
| `FULL_LIMIT` | المسح الكامل لكل الأسهم المدرجة كل 10 دقائق (`0` لإيقافه) | `10000` |
| `ALERT_PCT` | نسبة التغير للتنبيه | `10` |
| `ALERT_SPEED` | الزخم خلال 5 دقائق للتنبيه | `3` |
| `ALERT_VOL_RATIO` | السيولة × المعتاد للتنبيه | `3` |
| `BOT_TOKEN` / `CHAT_ID` | لتفعيل تنبيهات تيليجرام | — |

## التشغيل على Render
- Build: `pip install -r requirements.txt`
- Start: `gunicorn wsgi:app --workers 1 --threads 4`

## تشغيل المنصة تلقائيًا مع ويندوز (مرة واحدة فقط)
في PowerShell:
```powershell
cd $HOME\saudi-stocks-bot
git pull
.\start_platform.bat
```
بعدها كل شيء تلقائي: عند تشغيل الكمبيوتر تتحدث المنصة من GitHub، وتثبّت المكتبات الجديدة،
وتشتغل وتفتح في المتصفح. ويُضاف اختصار **Stocks Platform** على سطح المكتب.

- لإيقاف المنصة: أغلق نافذة **Stocks Platform** المصغّرة في شريط المهام
- لإلغاء التشغيل التلقائي: `uninstall_startup.bat`
