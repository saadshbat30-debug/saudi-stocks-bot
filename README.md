# 🇸🇦 بوت السوق السعودي (Saudi Stocks Bot)

بوت تيليجرام يعرض **بيانات حقيقية** للسوق السعودي (تاسي ونمو) من [واجهة سهمك للمطورين](https://www.sahmk.sa/developers) المرخّصة من تداول، عبر المكتبة الرسمية [`sahmk`](https://github.com/sahmk-sa/sahmk-python).

## المميزات
- سعر لحظي لأي سهم بإرسال الرمز أو الاسم (`2222`، `أرامكو`، `الراجحي`)
- ملخص مؤشر تاسي ونمو (القيمة، التغير، المرتفعة والمنخفضة)
- الأسهم الأكثر ارتفاعاً وانخفاضاً ونشاطاً بالكمية وبالقيمة
- أداء القطاعات
- البحث عن رموز الشركات
- أداء آخر 30 يوم لأي سهم
- قائمة متابعة لكل مستخدم
- تنبيهات سعرية **لحظية** عبر البث المباشر (WebSocket) من سهمك، مع فحص دوري احتياطي أثناء التداول (الأحد إلى الخميس، 10:00–15:10 بتوقيت الرياض)

**ميزات باقة برو:**
- بيانات الشركة: القيمة السوقية، مكرر الربحية، المؤشرات الفنية (RSI وMACD)، القيمة العادلة، توصيات المحللين
- قائمة الدخل، والتوزيعات مع العائد
- أخبار وإعلانات الشركات، وتصلك تلقائياً لأسهم قائمة متابعتك
- عمق السوق (أفضل 5 طلبات وعروض) وآخر الصفقات المنفذة
- أزرار سريعة تحت كل سعر سهم
- ملخص يومي عند الافتتاح والإغلاق يُرسل إلى `OWNER_CHAT_ID` (اختياري)

## الأوامر
| الأمر | الوصف |
|---|---|
| `2222` أو `الراجحي` | سعر السهم |
| `/market` أو `السوق` | مؤشر تاسي |
| `/nomu` | مؤشر نمو |
| `/gainers` `/losers` | الأكثر ارتفاعاً / انخفاضاً |
| `/volume` `/value` | الأكثر نشاطاً بالكمية / بالقيمة |
| `/sectors` | أداء القطاعات |
| `/search أرامكو` | بحث عن شركة |
| `/history 2222` | أداء آخر 30 يوم |
| `/company 2222` | الأساسيات والمؤشرات الفنية والقيمة العادلة والمحللون |
| `/financials 2222` | قائمة الدخل |
| `/dividends 2222` | التوزيعات |
| `/news` أو `/news 2222` | الأخبار والإعلانات |
| `/depth 2222` | عمق السوق |
| `/trades 2222` | آخر الصفقات |
| `/watch 2222 1120` / `/unwatch 2222` / `/watchlist` | قائمة المتابعة |
| `/alert 2222 > 30` / `/alerts` / `/delalert ID` | التنبيهات السعرية |

## الإعداد
1. أنشئ مفتاح API من [سهمك للمطورين](https://www.sahmk.sa/developers). البوت مصمّم لباقة **Pro**. في الباقات الأقل تظهر رسالة "غير متاحة في اشتراكك" لأوامر برو، ويتحول البوت للفحص الدوري تلقائياً إذا رُفض البث المباشر.
2. أنشئ بوتاً من [@BotFather](https://t.me/BotFather) وانسخ التوكن.
3. ضع المتغيرات (انظر `.env.example`):
   - `SAHMK_API_KEY`
   - `TELEGRAM_BOT_TOKEN`
   - `OWNER_CHAT_ID` (اختياري)

### التشغيل محلياً (بدون سيرفر)
السكربت ينشئ بيئة معزولة `.venv` داخل مجلد البوت، فلا يغيّر مكتبات Python لمشاريعك الأخرى. ويقرأ المفاتيح من ملف `.env`.

ويندوز:
```powershell
powershell -ExecutionPolicy Bypass -File start.ps1
```
لينكس/ماك:
```bash
./start.sh
```

### النشر على Render
الملف `render.yaml` جاهز. أنشئ Web Service من هذا المستودع وأضف المتغيرات. يقرأ البوت الرابط من `RENDER_EXTERNAL_URL` ويسجّل الـ webhook تلقائياً عند التشغيل.

> ملاحظة: الخطة المجانية في Render توقف الخدمة عند الخمول، فتتوقف التنبيهات حتى تصل رسالة جديدة. كما أن القرص مؤقت، فقد تُمسح قوائم المتابعة والتنبيهات عند إعادة التشغيل. للتشغيل المستمر استخدم خطة مدفوعة مع Persistent Disk (واضبط `DATA_DIR` عليه)، أو شغّل `run_polling.py` على أي سيرفر.

## هيكل المشروع
```
app.py            # Flask + webhook (للنشر)
run_polling.py    # تشغيل محلي بالـ long polling
bot/market.py     # جلب بيانات سهمك وتنسيقها
bot/handlers.py   # الأوامر والردود
bot/stream.py     # تنبيهات لحظية عبر WebSocket
bot/alerts.py     # تقييم التنبيهات (مشترك بين البث والفحص الدوري)
bot/scheduler.py  # الفحص الدوري، أخبار قائمة المتابعة، الملخص اليومي
bot/storage.py    # قوائم المتابعة والتنبيهات (JSON)
bot/telegram.py   # عميل Telegram Bot API
```
