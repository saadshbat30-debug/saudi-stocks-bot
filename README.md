# منصة الأسهم — السوق الأمريكي والسعودي

- أسعار من Yahoo Finance (مكتبة `yfinance`) تتحدث تلقائيًا كل 20 ثانية
- شارت TradingView لكل سهم
- تنبيه تيليجرام عند تغير السهم بنسبة معينة خلال اليوم

## الملفات
| الملف | الوظيفة |
|---|---|
| `config.py` | قوائم الأسهم والإعدادات — أضف أو احذف الأسهم هنا |
| `market.py` | سحب الأسعار من ياهو مع تخزين مؤقت |
| `alerts.py` | تنبيهات تيليجرام |
| `app.py` | صفحات الموقع |

## متغيرات البيئة (في Render ← Environment)
| المتغير | الوصف | الافتراضي |
|---|---|---|
| `BOT_TOKEN` | توكن بوت تيليجرام | — |
| `CHAT_ID` | رقم المحادثة | — |
| `ALERT_PCT` | نسبة التغير للتنبيه | `3` |
| `ALERT_INTERVAL` | كل كم ثانية يفحص التنبيهات | `60` |

## التشغيل على Render
- Build: `pip install -r requirements.txt`
- Start: `gunicorn wsgi:app --workers 1 --threads 4`

(عامل واحد فقط `--workers 1` حتى لا تتكرر التنبيهات)

## الصفحات
- `/market/us` السوق الأمريكي · `/market/sa` السوق السعودي
- `/stock/AAPL` صفحة السهم مع الشارت
- `/test` رسالة اختبار للبوت
