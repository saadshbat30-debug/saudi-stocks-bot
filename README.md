# منصة الأسهم الأمريكية — من أقل من 1$ إلى 60$

تعمل **بدون أي توكن أو مفتاح** — شغّلها وافتح الموقع.

- أسهم ناسداك ونيويورك وأمكس (بدون OTC) بسعر من 0 إلى 60$، مرتبة بالأكثر تداولًا (حتى 750 سهم)
- قائمة الأسهم من ماسح Yahoo Finance، والأسعار **لحظية** من البث المباشر لياهو (⚡) والصفحة تتحدث كل 5 ثوانٍ
- يستبعد الوارنتات والحقوق والوحدات والأسهم الممتازة
- فلاتر السعر: تحت 1$ · 1–5$ · 5–20$ · 20–60$
- فلاتر: المفضلة، الأكثر ارتفاعًا/انخفاضًا، سيولة عالية، تشبع بيعي/شرائي، اتجاه صاعد
- بحث بالرمز أو الاسم، ونجمة ★ للمفضلة، وإضافة أي رمز خارج النطاق
- أعمدة: السعر، التغير، الحجم، السيولة مقارنة بالمعتاد، RSI 14، القيمة السوقية
- تنبيهات داخل الموقع (صوت + إشعارات المتصفح) عند تغير ±10% أو سيولة 3× المعتاد
- صفحة لكل سهم مع **شارت لحظي** (شموع 1د/5د/15د/ساعة/يوم من ياهو، وآخر شمعة تتحدث من البث المباشر) + تبويب TradingView الكامل (متأخر 15 دقيقة)
- تنبيهات تيليجرام **اختيارية** (رسالة ملخص واحدة لكل دورة)

## التشغيل على جهازك (ويندوز)
```powershell
cd $HOME\saudi-stocks-bot
git pull
py -m pip install -r requirements.txt
py app.py
```
ثم افتح http://localhost:5000

## الإعدادات (كلها اختيارية — متغيرات بيئة)
| المتغير | الوصف | الافتراضي |
|---|---|---|
| `MIN_PRICE` / `MAX_PRICE` | النطاق السعري | `0` / `60` |
| `US_LIMIT` | أقصى عدد أسهم | `750` |
| `ALERT_PCT` | نسبة التغير للتنبيه | `10` |
| `ALERT_VOL_RATIO` | السيولة × المعتاد للتنبيه | `3` |
| `BOT_TOKEN` / `CHAT_ID` | لتفعيل تنبيهات تيليجرام | — |

## التشغيل على Render
- Build: `pip install -r requirements.txt`
- Start: `gunicorn wsgi:app --workers 1 --threads 4`
