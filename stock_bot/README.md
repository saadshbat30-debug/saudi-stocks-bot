# 📊 بوت تحليل الأسهم السعودية

بوت يقرأ ملفات CSV المُصدَّرة من **تكرتشارت**، ويطبّق عليها **12 فلترًا** ذكيًا لاكتشاف فرص الشراء والبيع، ثم يعرض النتائج في:

| المخرج | المسار | الوصف |
|---|---|---|
| ملف Excel | `output/signals.xlsx` | كل الأسهم + كل الأعمدة الأصلية + أعمدة الإشارات، ملوّن تلقائيًا (أخضر شراء / أحمر بيع) |
| سجل التنبيهات | `output/alerts.log` | الوقت، السهم، السعر، الإشارة، وكل التفاصيل |
| لوحة ويب | `http://localhost:8000` | جدول موحد، تبويبات لكل ملف، الإشارات القوية، رسوم بيانية، تنبيهات منبثقة وصوتية |

✅ لا يستخدم تليجرام ولا أي API خارجي — كل شيء يعمل على جهازك، حتى بدون إنترنت.
✅ مصمم للعمل على **Windows** (ويعمل أيضًا على Mac و Linux).

> ⚠️ **تنبيه:** هذا البوت أداة مساعدة للتحليل الفني فقط، وليس توصية بالشراء أو البيع. القرار الاستثماري مسؤوليتك.

## 🚀 التشغيل خطوة بخطوة (Windows)

### 1) تثبيت Python
- حمّل **Python 3.10 أو أحدث** من [python.org](https://www.python.org/downloads/).
- ⚠️ أثناء التثبيت فعّل خيار **"Add Python to PATH"**.
- تأكد من التثبيت: افتح **Command Prompt** (اكتب `cmd` في قائمة ابدأ) واكتب:
  ```
  python --version
  ```

### 2) تنزيل المشروع إلى جهازك
- حمّل المشروع كملف ZIP من GitHub (زر **Code ← Download ZIP**) وفك الضغط مثلًا على سطح المكتب.
- المجلد المهم هو `stock_bot` داخل المجلد المفكوك.
- **أسهل طريقة:** افتح مجلد `stock_bot` وانقر نقرتين على **`run.bat`** — يثبّت المكتبات ويشغّل البوت تلقائيًا.

### 3) تثبيت المكتبات يدويًا (إذا لم تستخدم run.bat)
افتح PowerShell **داخل مجلد stock_bot** (افتح المجلد ← اضغط Shift + زر الفأرة الأيمن ← "Open PowerShell window here")، ثم:
```
py -m pip install -r requirements.txt
```
> استخدم `py -m pip` بدل `pip` — أضمن على Windows إذا كان عندك أكثر من نسخة Python.

### 4) تجربة البوت بالبيانات التجريبية (اختياري)
المجلد `data/` يحتوي بيانات تجريبية جاهزة لـ 12 سهمًا. لتوليد بيانات جديدة:
```
python sample_data.py
```
ولمحاكاة تحديث لحظي كل 30 ثانية (في نافذة منفصلة):
```
python sample_data.py --loop 30
```
> ⚠️ هذا الأمر **يستبدل** ملفات `data/` — لا تشغّله على بياناتك الحقيقية.

### 5) تشغيل البوت
```
py bot.py
```
أو انقر نقرتين على **`run.bat`**.

سيحدث التالي:
1. تحليل فوري لكل الملفات.
2. إنشاء `signals.xlsx` و `alerts.log`.
3. تشغيل لوحة الويب وفتح المتصفح تلقائيًا على `http://localhost:8000`.
4. مراقبة مجلد `data/` — أي تحديث لملف CSV يعيد التحليل خلال ثوانٍ.
5. إعادة التحليل كل 5 دقائق تلقائيًا (حتى لو لم تتغير الملفات).

للإيقاف: اضغط **Ctrl + C** في نافذة الأوامر.

### خيارات إضافية
| الأمر | الوظيفة |
|---|---|
| `python bot.py --once` | تحليل مرة واحدة ثم الخروج (مفيد للجدولة في Task Scheduler) |
| `python bot.py --no-dashboard` | بدون لوحة الويب |
| `python bot.py --no-browser` | تشغيل اللوحة بدون فتح المتصفح تلقائيًا |
| `python bot.py --config my.yaml` | استخدام ملف إعدادات آخر |
| `python dashboard.py` | تشغيل لوحة الويب وحدها لعرض آخر نتائج محفوظة |

### 6) فتح لوحة التحكم
افتح المتصفح على: **http://localhost:8000**

لفتحها من الجوال على نفس شبكة الواي فاي: غيّر في `config.yaml`:
```yaml
output:
  dashboard_host: "0.0.0.0"
```
ثم افتح `http://<IP جهازك>:8000` (اعرف IP جهازك بالأمر `ipconfig`). قد يطلب جدار حماية Windows السماح — وافق للشبكات الخاصة فقط.

## 📥 إدخال البيانات من لوحة الويب (الأسهل)

> ⚠️ البيانات الموجودة عند التنزيل **تجريبية (وهمية)** — تظهر في أعلى اللوحة لافتة حمراء تنبهك لذلك.

افتح تبويب **📥 إدخال البيانات** في لوحة التحكم:

1. في تكرتشارت حدد الجدول كاملًا (**Ctrl + A**) وانسخه (**Ctrl + C**).
2. الصقه في المربع (**Ctrl + V**) — يجب أن يكون السطر الأول أسماء الأعمدة.
3. اختر نوع البيانات (سهمك، السيولة، ...) أو اتركه **تحديد تلقائي** — البوت يتعرف على النوع من أسماء الأعمدة.
4. اضغط **🔍 معاينة**: ترى أول الصفوف، والأعمدة التي تعرّف عليها ✓ والناقصة ✗.
5. اضغط **💾 حفظ وتحليل**: تُحفظ البيانات في مجلد `data/` ويُعاد التحليل فورًا.

أو **اسحب ملفات** CSV / Excel (.xlsx) إلى المربع المخصص — يمكن رفع الملفات الثمانية مرة واحدة، وكل ملف يُحدد نوعه من اسمه أو أعمدته.

- خيار **"إضافة للبيانات الموجودة"** يضيف الصفوف للملف بدل استبداله (مفيد للبيانات اللحظية `ticks`).
- عند أول إدخال لبيانات حقيقية **تُحذف البيانات التجريبية تلقائيًا** وتُمسح تنبيهاتها حتى لا تختلط.
- زر **🗑️ حذف كل البيانات** يفرّغ مجلد `data/` بالكامل.

## 📤 ربط البوت مع تكرتشارت (تلقائي عبر ملفات CSV)

1. في تكرتشارت، صدّر كل شاشة (سهمك، السيولة، المتوسطات...) إلى CSV.
2. احفظ الملفات في مجلد `data/` **بنفس الأسماء** (`sahmak.csv`، `liquidity.csv`، ...).
   - أو غيّر الأسماء في `config.yaml` تحت `data → files`.
   - أو غيّر المجلد كله: `data → input_folder: "C:/TickerChart/Export/"`.
3. اجعل التصدير يتكرر كل 5 دقائق — البوت يلتقط التحديث تلقائيًا.

### متطلبات الملفات
- **عمود الرمز (`الرمز`)** يجب أن يكون موجودًا في كل ملف، حتى يعرف البوت لأي سهم ينتمي كل صف.
  - إذا كان ملف مثل `ticks.csv` لسهم واحد بدون عمود رمز:
    - إذا كان `sahmak.csv` يحتوي سهمًا واحدًا فقط ← يُنسب إليه تلقائيًا.
    - وإلا حدد السهم في `config.yaml`: `data → default_symbol: "2222"`.
- إذا تكرر السهم في عدة صفوف (مثل `liquidity.csv` و `ticks.csv`) ← يأخذ البوت **آخر صف زمنيًا** لكل سهم.
- الترميزات المدعومة تلقائيًا: UTF-8 (مع أو بدون BOM)، Windows-1256 العربي، UTF-16.
- الفواصل المدعومة تلقائيًا: فاصلة `,` أو فاصلة منقوطة `;` أو Tab.
- الأرقام المدعومة: `1,234.5` و `12.5%` و `(500)` و `١٢٣` و `1.5M` و `250K`.

### إذا كانت أسماء الأعمدة عندك مختلفة
لا تعدّل الكود — عدّل قسم `columns` في `config.yaml` فقط. مثال: لو كان عمود RSI عندك اسمه "RSI 14":
```yaml
columns:
  rsi_stoch:
    rsi: ["RSI", "RSI 14"]     # يمكن وضع عدة أسماء بديلة
```
المطابقة لا تتأثر بالمسافات الزائدة ولا بحالة الأحرف الإنجليزية.

**نصيحة:** افتح تبويب **"📁 حالة الملفات"** في لوحة الويب — يوضح هل كل ملف موجود، وعدد صفوفه، وآخر تعديل. وإذا ظهر في أي فلتر "— لا توجد بيانات" فمعناه أن العمود المطلوب لم يُعثر عليه.

## 🔍 الفلاتر الـ 12 وطريقة احتساب النقاط

كل فلتر يرجع نصًا ونقاطًا: **+1** إيجابي (شراء) ، **−1** سلبي (بيع) ، **0** محايد أو معلوماتي.

| # | الفلتر | المصدر | الشرط | النقاط |
|---|---|---|---|---|
| 1 | صافي السيولة | liquidity.csv | > 500,000 🟢 شراء قوي / < −500,000 🔴 بيع قوي | +1 / −1 |
| 2 | الصفقات الكبيرة | ticks.csv (حجم آخر) | > 50,000 ⚠️ صفقة كبيرة | 0 (معلوماتي) |
| 3 | نسبة السيولة | liquidity.csv | > 80 🟢 / < 20 🔴 | +1 / −1 |
| 4 | التوقيت | وقت البيانات | 09:30–11:30 🌅 تجميع / بعد 14:00 🌇 تصريف | 0 (معلوماتي) |
| 5 | متوسط 10 | sahmak + moving_avg | السعر > المتوسط 10 ✅ | +1 / −1 |
| 6 | RSI | rsi_stoch.csv | > 70 🔴 تشبع شرائي / < 30 🟢 تشبع بيعي | −1 / +1 |
| 7 | اتجاه الصفقة | ticks.csv | اتجاه 1 وحجم > 50,000 🟢 / اتجاه −1 🔴 | +1 / −1 |
| 8 | اختراق المتوسطات | breakout.csv | اختراق متوسط 10 ✅ / تقاطع 5 مع 20 🚀 | +1 / −1 |
| 9 | Aroon | aroon_macd.csv | Up > 70 🟢 / Down > 70 🔴 | +1 / −1 |
| 10 | MACD | aroon_macd.csv | MACD > Signal 🟢 | +1 / −1 |
| 11 | Stochastic | rsi_stoch.csv | K > 80 🔴 / K < 20 🟢 | −1 / +1 |
| 12 | CMF | aroon_macd.csv | > 0.1 🟢 / < −0.1 🔴 | +1 / −1 |

### ملاحظات على المنطق
- **فلتر 1 و 3:** إذا لم يوجد عمود "صافي السيولة" أو "نسبة السيولة %" يحسبهما البوت من (قيمة الشراء − قيمة البيع) في `liquidity.csv`، وإن لم يوجد ففي `sahmak.csv`.
- **فلتر 2 و 7:** المقارنة افتراضيًا بـ"حجم آخر" (عدد الأسهم). للمقارنة بالقيمة بالريال: `big_trade_field: "value"`.
- **فلتر 4:** يأخذ الوقت من عمود "الوقت" في البيانات. لاستخدام ساعة الجهاز: `timing_source: "clock"`.
- **فلتر 8:** يفهم قيمًا رقمية (`1` / `-1` / `0`) أو نصية: "صاعد"، "اختراق"، "نعم"، "✓" = إيجابي — و"هابط"، "كسر"، "سلبي" = سلبي — والخلية الفارغة أو "لا" = لا يوجد اختراق.
- **فلتر 6 و 11:** التشبع البيعي يُحسب فرصة شراء (+1) والتشبع الشرائي خطر (−1).

### التصنيف النهائي (من `scoring` في config.yaml)
| مجموع النقاط | الإشارة |
|---|---|
| ≥ 4 | 🟢🟢 شراء قوي ← **تنبيه** |
| 2 إلى 3 | 🟢 شراء |
| −1 إلى 1 | ⚪ محايد |
| −3 إلى −2 | 🔴 بيع |
| ≤ −4 | 🔴🔴 بيع قوي ← **تنبيه** |

الأسهم مرتبة تنازليًا حسب النقاط، ثم حسب صافي السيولة.

## 🔔 التنبيهات

متى يُسجَّل تنبيه؟
1. **إشارة قوية:** عندما يصبح السهم "شراء قوي" أو "بيع قوي" (مرة واحدة فقط — لا يتكرر في كل دورة طالما الإشارة نفسها).
2. **صفقة كبيرة:** كل صفقة لحظية كبيرة جديدة باتجاه شراء أو بيع (يمكن إيقافها: `log_big_trades: false`).

أين تظهر؟
- **`output/alerts.log`** — سطر لكل تنبيه، مثال:
  ```
  [2026-10-05 10:15:31] | إشارة قوية | 2280 المراعي | السعر: 55.03 | الإشارة: 🟢🟢 شراء قوي (النقاط: +6) | التفاصيل: صافي السيولة: 4,081,462 ; نسبة السيولة %: 78.95 ; RSI: 73.40 ; ...
  ```
- **لوحة الويب** — إشعار منبثق في زاوية الشاشة + صوت تنبيه + رقم أحمر على تبويب التنبيهات.
  - زر **💬 إشعارات المتصفح** يفعّل إشعارات سطح المكتب حتى لو كانت النافذة مصغرة.
  - المتصفحات تمنع الصوت حتى تضغط على الصفحة مرة واحدة على الأقل.
- **صوت Windows** عبر `winsound` (يمكن إيقافه: `alerts → sound: false`). ضع ملف `alert.wav` في مجلد المشروع لاستخدام صوتك الخاص، وإلا يُستخدم صوت Windows الافتراضي.

## 🛠️ التعديل والتطوير

### إضافة فلتر جديد (مثال: فلتر MFI)
1. افتح `filters.py` واكتب دالة جديدة:
   ```python
   def filter_13_mfi(d: dict, cfg: dict):
       """فلتر 13: مؤشر تدفق الأموال MFI."""
       mfi = d.get("mfi")
       if mfi is None:
           return NO_DATA, 0
       if mfi > 80:
           return "🔴 MFI تشبع شرائي", -1
       if mfi < 20:
           return "🟢 MFI تشبع بيعي", 1
       return "⚪ محايد", 0
   ```
2. أضفها إلى القائمة `FILTERS` في آخر `filters.py`:
   ```python
   FilterDef("f13", "ف13 MFI", filter_13_mfi),
   ```
3. في `bot.py` داخل الدالة `build_inputs` أضف القيمة إلى القاموس المُرجَع:
   ```python
   "mfi": n("rsi_stoch", "mfi"),
   ```
   (الحقل `mfi` معرّف مسبقًا في `config.yaml` تحت `columns → rsi_stoch`).

انتهى! الفلتر الجديد سيظهر تلقائيًا في Excel ولوحة الويب والتنبيهات، ويدخل في حساب النقاط.

### تعطيل فلتر
ضع `#` قبل سطره في قائمة `FILTERS` في `filters.py`.

### تغيير حدود الفلاتر
من `config.yaml` فقط — لا حاجة لتعديل الكود.

## ❓ حل المشاكل الشائعة

| المشكلة | الحل |
|---|---|
| `'python' is not recognized` | أعد تثبيت Python مع تفعيل "Add Python to PATH"، أو استخدم `py bot.py` |
| `ModuleNotFoundError` | شغّل `py -m pip install -r requirements.txt` |
| `can't open file ...bot.py` | أنت لست داخل مجلد stock_bot — انتقل إليه بالأمر `cd` أولًا |
| `Fatal error in launcher` عند pip | استخدم `py -m pip` بدل `pip` |
| "الملف مفتوح في Excel" | أغلق `signals.xlsx` في Excel — Windows يقفل الملف المفتوح. سيتحدث في الدورة القادمة |
| الفلاتر تظهر "— لا توجد بيانات" | اسم العمود في ملفك مختلف — عدّله في `config.yaml → columns` وراجع تبويب "حالة الملفات" |
| البوت لا يلتقط التحديثات | إذا كان المجلد على OneDrive أو شبكة: `use_polling: true` |
| المنفذ 8000 مستخدم | غيّر `dashboard_port` إلى 8080 مثلًا |
| الحروف العربية تظهر رموزًا في الملف | أضف ترميز ملفك إلى `data → encodings` |
| لا يوجد صوت في المتصفح | اضغط على الصفحة مرة واحدة (سياسة المتصفحات) وتأكد أن زر الصوت "يعمل" |
