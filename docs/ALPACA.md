# بث Alpaca (SIP) — Algo Trader Plus

طبقة مستقلة (`alpaca_stream.py`) تستقبل الصفقات والأسعار وشموع الدقيقة لكل الأسهم الأمريكية من مصدر SIP عبر WebSocket.
لا تغيّر وظائف المنصة الحالية، ولا تحتوي أي كود لإرسال أوامر، وحساب التداول المسموح Paper فقط.

## مصدر بيانات المنصة (DATA_SOURCE=alpaca)

| الجزء | من Alpaca | يبقى من ياهو |
|---|---|---|
| الجدول | السعر، التغير، الإغلاق السابق، حجم اليوم، أعلى/أدنى اليوم، قيمة التداول (VWAP × الحجم)، السيولة النسبية (متوسط 3 أشهر من Alpaca)، RSI ومتوسطا 20 و50، سرعة 5 دقائق | قائمة الأسهم، الاسم، الأسهم الحرة والقائمة (التدوير)، القيمة السوقية، P/E، الشرعية |
| الشارت وسلّم الضغط | كل الفواصل (REST، SIP) | — |
| صفحة السهم | السعر اللحظي وشريط الصفقات (صفقات Alpaca) والأخبار (Benzinga) ونطاق 52 أسبوعًا (شموع Alpaca اليومية) | البيانات الأساسية |
| رادار الزخم | كل الحقول (SIP لحظي، كان TradingView متأخرًا 15 دقيقة) | — |
| قبل الانطلاق | آخر 3 دقائق من صفقات Alpaca لمرشحيه (حتى 200 سهم) | الأسهم الحرة |
| الماسح الشامل | مزود Alpaca | — |
| العقود | OPRA لحظي: السعر، الحجم، التذبذب الضمني، العقود المفتوحة (التذبذب الذي لا يرسله Alpaca يُحسب من منتصف العرض والطلب ويُعلَّم ≈) | — |
| السيولة اللحظية | صفقات وأسعار SIP مصنفة شراءً/بيعًا (NBBO ثم tick rule) | — |
| التداول الليلي | feed=overnight | — |
| المؤشرات (داو، ناسداك…) | — | ياهو (Alpaca لا يوفر المؤشرات) |
| السوق السعودي وOTC | — | ياهو / منصة أبو طلال (تاريخ ياهو اليومي يُجلب لأسهم OTC فقط) |
| إعلانات التقسيم والشطب | — | تقويم ياهو وSEC وناسداك |

- كل الصفقات لكل السوق لا تُستقبل: اتصال المستخدم إلى أمريكا (338ms ذهابًا وإيابًا) لا يحملها. لكل السوق شموع اليوم كل دقيقة،
  وصفقات لحظية لـ: السهم المفتوح + أنشط 40 (صفقات وأسعار وشموع دقيقة، `ALPACA_WATCH_MAX`) + مرشحي قبل الانطلاق
  (صفقات فقط، `ALPACA_TAPE_MAX`).
- بث ياهو يتوقف للأسهم الأمريكية؛ يبقى للمؤشرات والأسواق الأخرى.
- عند فشل Alpaca في أي جزء: ياهو بدلًا منه مع ذكر السبب، وطلبات Alpaca تتوقف 10 دقائق بعد رفض المفتاح.
- قبل الافتتاح لا تُرسل شموع اليوم: الأسهم غير المتابَعة تبقى بسعر ياهو حتى الافتتاح.

## الإعداد
1. انسخ `.env.example` إلى `.env` في مجلد المنصة وضع مفاتيح **Paper** من لوحة Alpaca.
   `.env` مستثنى من Git (`.gitignore`) ولا يُرفع.
2. `py -m pip install -r requirements.txt`
3. أوقف المنصة إن كانت تعمل، ثم: `py alpaca_check.py` (90 ثانية، أثناء الجلسة 4:00–20:00 نيويورك).
4. بعد نجاح الفحص: `ALPACA_STREAM=1` في `.env` ثم `py app.py`. الحالة: http://127.0.0.1:5000/api/alpaca/status

## حدود معروفة
- Alpaca يسمح غالبًا باتصال بث واحد: المنصة وأداة الفحص لا تعملان معًا (الخطأ 406).
- كل الصفقات عبر SIP نحو 10 ميغابت/ث دون ضغط عند 10 آلاف صفقة/ث. الاتصال يطلب ضغط permessage-deflate (مكتبة
  websockets)، وأداة الفحص تطبع هل قُبل، وحجم البيانات، وانشغال معالج الاستقبال، لتحديد هل الحد الإنترنت أم المعالج.
  فحص 2026-11-18 الأول (بلا ضغط): الاستقبال بقي 4–5 آلاف رسالة/ث، وتأخرت الصفقات 12 ث، ثم قطع الخادم الاتصال.
- فحص 2026-11-18 الثالث: معالج الاستقبال 2–12% فقط، وAlpaca لم يقبل الضغط، والاستقبال يبدأ لحظيًا (720 KB/ث،
  تأخير 0.5 ث) ثم ينزل إلى 130–350 KB/ث حتى يقطع الخادم. الحد إذن مسار الإنترنت إلى Alpaca لا الكود.
  الترميز الافتراضي صار msgpack (`ALPACA_FORMAT=msgpack`): نصف حجم JSON (قيس 368 مقابل 733 KB لـ 6000 صفقة).
  إن بقي التأخير، فالحل العملي: الشموع لكل السوق (`ALPACA_BARS=*`) والصفقات والأسعار لقائمة أسهم.
- الأسعار (quotes) لكل السوق كثيفة جدًا. المعالجة قيست هنا بنحو 210 ألف رسالة/ثانية على خيط واحد، لكن سرعة
  الإنترنت وجهازك قد تكون الحد. إن ظهر 407 (slow client) اجعل `ALPACA_QUOTES` قائمة رموز أو `off`.
- التأخير المقاس = وقت الاستلام على جهازك − وقت الحدث في البورصة، فيتضمن فرق ساعة الجهاز (أداة الفحص تقيسه).
- البيانات متاحة عبر `alpaca_stream.latest_trade/latest_quote/minute_bars` و`/api/alpaca/status`؛
  لم تُربط بعد بحسابات الماسح والشارت (ربطها مرحلة لاحقة بموافقتك).
- يبدأ البث مع `py app.py` فقط (لا مع gunicorn/wsgi).

## الأخطاء
| الرمز | المعنى | سلوك المحرك |
|---|---|---|
| 402 | المفتاح أو السر خطأ | يتوقف ولا يعيد المحاولة |
| 409 | الاشتراك لا يشمل SIP | يتوقف، ولا يرجع إلى IEX |
| 406 | اتصال آخر مفتوح | ينتظر 60 ث ثم يعيد |
| 407 | جهازك أبطأ من البيانات | يعيد الاتصال؛ قلّل الرموز |
| انقطاع شبكة/خادم | — | إعادة اتصال بانتظار 1، 2، 4… حتى 60 ث |
| لا بيانات 30 ث أثناء التداول | اتصال معلق | إعادة اتصال |
