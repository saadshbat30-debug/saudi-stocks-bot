# تدقيق نظام «السيولة» (ضغط الشراء/البيع التقديري) — 2026-11-15

بيانات ياهو الخام كما وصلت (30 سهمًا × 6 فواصل، 5–13 نوفمبر 2026، جُلبت 2026-11-15 والسوق مغلق) والسكربتات
التي أنتجت أرقام تقرير التدقيق. لا شيء هنا يُستعمل في تشغيل المنصة.

- `raw_yahoo_2026-11-15.tar.xz` — 180 ملف CSV (13MB بعد الفك). `common.py` يفكه تلقائيًا إلى `raw/` (خارج Git).
- `fetch.py` — الجلب (يكتب فوق `raw/`؛ البيانات الجديدة ستختلف لأن ياهو يحتفظ بشموع الدقيقة 7 أيام فقط).
- `old_filter.py` — نسخة حرفية من فلتر الأحجام قبل الإصلاح (الإيداع af8eae9)، مرجع «قبل».
- `results/` — مخرجات السكربتات وقت التدقيق.

| السكربت | ما يقيسه |
|---|---|
| `t1_sessions.py` | حجم كل جلسة (قبل الافتتاح/الرسمية/بعد الإغلاق) مقابل الشمعة اليومية |
| `t2_intervals.py` | مجموع كل فاصل ÷ حجم اليوم (أيّ الفواصل معطوب في أيّ يوم) |
| `t3_truth.py`, `t4_filter_real.py`, `t6_cases.py` | حقيقة مرجعية أولية وأخطاء الفلتر القديم |
| `t5_identity.py` | هل مجموع الفاصل الأصغر = شمعة الفاصل الأكبر في بيانات ياهو |
| `t7_score.py` | تقييم الفلتر القديم والبديل الأولي على شموع الدقيقة |
| `t8_hourly.py`, `t8b_hourly_min.py` | فاصل الساعة: الفلتر القديم وقاعدة «أصغر المصادر» |
| `t9_equation.py` | المعادلة على اللوحة والسلّم والمؤشر السفلي وبكل فاصل |
| `t10_post.py` | شمعة ما بعد الإغلاق التي تحمل حجم اليوم (احتساب مزدوج) |

التشغيل: `cd docs/liquidity_audit && python3 t7_score.py`

كل أرقام «الضغط» تقدير من شموع OHLCV (موقع الإغلاق داخل مدى الشمعة × قيمتها)، وليست تنفيذات مصنفة شراءً وبيعًا.
